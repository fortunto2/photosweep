# 1.1 privacy changes — check before submitting 1.1

The live policy (superduperai.co/products/photosweep/privacy/, updated 2 Nov 2026) already
discloses the counter, but names only one event, "app launched". 1.1 sends more:

| Event | Props / metrics |
|---|---|
| `app_launched` | — |
| `scan_started` / `scan_finished` | cache warm/cold; items, seconds, freshly measured, videos, screenshots, total GB |
| `similar_scan_started` / `similar_scan_finished` | scope; photos, analyzed, seconds, groups, blurry, reclaimable MB |
| `group_reviewed` | duplicate/similar; items in group |
| `photos_deleted` | source (quick_clean, group, blurry, videos, screenshots); count, MB |

No photo, file name, asset id or location is in any of them. 1.1 also adds an in-app switch:
Storage tab → "Share anonymous usage counts" (`Analytics.isEnabled`).

## Policy: replace the "What reaches us" bullet

> Anonymous usage counts: that the app was opened, how long a scan took and how many items it
> found, how many duplicate groups it showed, and how many items you deleted and their total
> size, each with the app version, a timestamp and a random install id (see Analytics). You
> can switch them off in the Storage tab.

…and move "Last updated". Same edit in "What the app sends to us".

## App Privacy in App Store Connect

Must read (package README): Usage Data → Product Interaction and Identifiers → Device ID, both
not linked, not tracking, purpose Analytics. Could not be checked from here: `asc web privacy
pull --app 6794369239` needs a web session with 2FA.
